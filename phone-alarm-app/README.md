# 📵 폰 휴식 알람 (안드로이드)

핸드폰 화면이 켜져 있는 시간을 재서, **1시간(설정 가능) 사용할 때마다 알람**을 울려주는 앱.

## 기능
- 화면 켜짐 시간을 백그라운드에서 측정 (상단 알림에 오늘 사용 시간 표시)
- 연속 사용이 30 / 60 / 90 / 120분에 도달하면 알람(소리+진동) → 카운트 0부터 다시
- 화면을 5 / 10 / 15분 이상 꺼두면 '쉬었다'고 보고 연속 사용 시간 초기화
- 오늘 총 사용 시간, 오늘 울린 알람 횟수
- 재부팅해도 자동으로 다시 측정
- 알람 미리 울려보기, 배터리 최적화 해제 바로가기

## 설치
GitHub 저장소 → **Actions → "폰 휴식 알람 APK 빌드"** → 최근 실행 → 맨 아래 Artifacts의
`phone-break-alarm-apk`(zip) 를 받아 압축을 풀고 `phone-break-alarm.apk` 를 폰에 설치.

## 구조
- `UsageService.java` : 화면 켜짐/꺼짐을 감지해 시간을 재고 알람을 울리는 서비스
- `MainActivity.java` : 메인 화면
- `Notifier.java` : 알림/알람
- `Prefs.java` : 설정·기록 저장
- `BootReceiver.java` : 재부팅 후 자동 시작
